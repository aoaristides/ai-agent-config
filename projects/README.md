# Projetos

Cada projeto pode usar `example-project/` como referência inicial:

- `context.md`: problema, domínio, escopo e NFRs;
- `architecture.md`: estado atual/alvo e fluxos;
- `decisions.md`: decisões consolidadas; evolua para ADRs separados quando crescer;
- `open-questions.md`: dúvidas que mudam decisões;
- `notes.md`: notas transitórias úteis ao projeto.

O cofre Obsidian continua canônico para estado vivo e decisões reais. Use esta pasta para contexto portátil que precisa acompanhar o repositório; não duplique notas sem definir qual fonte prevalece.
