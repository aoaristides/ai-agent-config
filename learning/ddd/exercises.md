# Exercícios — DDD

## 1. Linguagem

Escolha um fluxo real e identifique cinco termos que mudam de significado entre áreas.

## 2. Aggregate

Modele uma invariável que precisa ser atômica. Defina raiz, comandos válidos e o que fica fora da transação.

## 3. Context map

Desenhe duas fronteiras, autoridade dos dados e padrão de relação. Justifique se precisa de ACL.

## 4. Anti-DDD

Descreva um CRUD em que DDD tático adicionaria mais custo do que valor.
