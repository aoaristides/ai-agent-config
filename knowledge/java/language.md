# Java — linguagem

## Defaults úteis

- Modele estados inválidos para serem difíceis de criar.
- Prefira imutabilidade e composição.
- Use records para dados imutáveis de borda quando a semântica permitir.
- Trate `Optional` como retorno de ausência, não como campo universal.
- Não capture exceção genérica sem política clara.

Legibilidade e invariantes vêm antes de abstrações reutilizáveis prematuras.
