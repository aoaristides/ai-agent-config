# Java moderno

Recursos modernos devem reduzir complexidade, não apenas modernizar sintaxe.

- records: dados imutáveis com identidade estrutural;
- sealed types: hierarquias fechadas e estados conhecidos;
- pattern matching: tratamento explícito de variantes;
- virtual threads: alta concorrência para I/O bloqueante com código simples;
- text blocks: contratos e payloads legíveis em testes.

Confirme a versão mínima do runtime e das bibliotecas antes de adotar.
