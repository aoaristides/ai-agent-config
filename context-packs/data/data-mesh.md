# Context Pack: Data Mesh

## Carregar quando

A tarefa tratar dados como produto, ownership por domínio, interoperabilidade ou
governança federada. Não carregar apenas porque há pipeline ou lakehouse.

## Perguntas mínimas

- Qual domínio possui o dado e responde pelo contrato?
- Quem são os consumidores e quais SLOs do produto de dados?
- Como schema, qualidade, lineage, descoberta e acesso são governados?
- Quais capacidades são self-service e quais continuam centralizadas?
- O time tem autonomia real para operar o produto de dados?

## Guardrail

Não use Data Mesh como sinônimo de plataforma de dados nem crie ownership nominal
sem responsabilidade operacional.
